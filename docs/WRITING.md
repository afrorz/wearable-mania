# Wearable Mania の書き方

身につけるガジェットの新製品を、1記事1製品で紹介する。どの記事でも「日本で使えるか」の欄で、
**技適**と**日本で使えない機能**に答える。ここが他のウェアラブルのサイトとの差。

## 載せる物

- 腕(時計・バンド)、指(リング)、顔(メガネ)、耳(イヤホン・補聴)、首・胸、服・靴、変なところ(外骨格など)
- 新しい技術・ギミック・数字で尖っている物。発表か発売から1か月ほどの物
- 日本で買える物も、まだ買えない物も載せる。本数は週3本まで(新しいドメインで急に増やさない)
- 載せない: セール・値下げ、「◯選」の買い方ガイド、リークだけの話

## 絶対に破らないこと(Gadget Terminal と同じ)

- **数字は、メーカー公式ページと出典の記事にあるものだけ。** 無い数字は書かない。仕様表に入れない
- **円に換算しない。** 価格は出ている通貨のまま(「1,990元」「399ドル」)。国内価格は国内で出ている円だけ
- 価格・在庫には「掲載時点」と付ける
- 1社しか報じていない話は、そう書く。リークはリークと書く
- 翻訳ではなく再構成。元の文を訳して並べない
- 実機は使っていない。「レビュー」「使ってみた」と名乗らない
- **動く映像(任意、2026-11-19〜)**: メーカー自身の公式 YouTube 動画から、3秒・音なしで1カットだけ切り出して `content/clips/<slug>/top.mp4` と `top.jpg`(最初のコマ)に置き、front matter の `clip:`(file / poster / credit / source)に書く。トップの一番大きいカードと記事の頭がこの映像になる。チャンネルがメーカー公式か(公式サイトからリンクされているか)を確かめる。レビューの人の動画は使わない。切り出しは `shorts\gadget-shorts` の `scripts\get_clip.py`
- 画像はメーカー公式ページ(公式ストアを含む)の画像の URL を `thumbnail` に書いてホットリンクし、`thumbnail_credit` に出典。ほかのニュースサイトの画像は使わない。ダウンロードしない
- 煽らない。感嘆符と絵文字を使わない
- **題名と summary に否定の結論を書かない**(「日本未発売」「技適なし」など)。日本や技適を入れるなら問いの形(「〜、日本で使える？」)

## 技適の書き方

総務省の「技術基準適合証明等を受けた機器の検索」で確かめる。`media\GadgetTerminal\scripts\giteki.py`
(`python scripts/giteki.py --model <型番>` か `--name <登録者名>`)で引ける。

| `jp.giteki.mark` | 書いてよいとき | 書き方の例 |
|---|---|---|
| `ok` | 総務省の検索で**番号まで**確かめた。または、日本法人・正規代理店が国内で正規に売っている | 「技適あり(番号 ◯◯◯-◯◯◯◯◯◯)」/「国内正規品。技適番号は未確認」 |
| `q` | 検索で見つからない・型番が分からない | 「総務省の検索では見つからない(掲載時点)」 |
| `none` | 電波を出さない | 「対象外(無線なし)」 |

- **検索で見つからなくても「技適なし」とは断定しない。** 型番が申請時と違うことが多い。`ng` は使わない
- 「違法」「電波法違反」と書かない(法律の説明は本人が見てから)。「国内で無線を使うには技適が要る」までにする

## 「日本で使える？」の欄(front matter の `jp`)

各項目は `mark`(ok / q / ng / none)と `text`(1文、60字まで)。

| 項目 | 何を書くか |
|---|---|
| `giteki` | 上の表のとおり。必須 |
| `buy` | 国内で正規に買えるか。輸入店(AliExpress 公式店など)なら店名と価格。必須 |
| `app` | 使うアプリが日本のストアにあるか・中国版だけか。分からなければ q。必須 |
| `lang` | 本体とアプリが日本語か英語に対応しているか。必須 |
| `health` | 健康の機能があるとき。日本で使えない・医療機器の承認がない機能(心電図・血圧・血糖など)はここ |
| `pay` | 決済の機能があるとき(Suica・中国の決済など) |

`verdict` に結論を1文。読者が次にとる行動(買う/待つ/代わりを買う)まで書く。

## front matter

```yaml
---
title: "Casio のリング CRW-H001、体温まで測って1,990元。日本で使える？"
slug: casio-crw-h001-smart-ring     # 英小文字とハイフン
date: 2026-11-19
part: finger          # wrist / finger / face / ear / neck / body / weird
maker: Casio
model: CRW-H001
summary: 一覧に出る1文(80字まで)
thumbnail: https://...(メーカー公式の画像)
thumbnail_credit: Casio 公式サイト
price: "1,990元(中国、掲載時点)"
status: china-only    # china-only(中国だけ)/ overseas(海外だけ)/ import(輸入で買える)/ japan(国内で買える)/ crowdfunding
jp:
  giteki: {mark: q, text: "総務省の検索では見つからない(掲載時点)"}
  buy: {mark: ng, text: "国内の正規販売はまだ無い"}
  app: {mark: q, text: "..."}
  lang: {mark: q, text: "..."}
  health: {mark: q, text: "..."}
  verdict: "..."
specs:                # 公式か出典にある数字だけ。[項目, 値]
  - ["重さ", "約4g"]
stores:               # 国内の楽天・Amazon・Yahoo で売っているときだけ。検索の言葉
  query: "INMO GO3"
alternatives:         # 国内で今買える、近い製品(1〜2個)。実在と国内販売を確かめた物だけ
  - name: "..."
    why: "なぜ代わりになるか(1文)"
    query: "楽天などで検索する言葉"
sources:
  - title: "..."
    url: "https://..."
    publisher: "..."
---
```

`stores` が無いときは買うボタンを出さない。`alternatives` の `query` は代わりの製品の買うボタンになる。

## 本文(600〜1,200字)

- 冒頭に1〜2文で「何が新しいか」
- `## ここが面白い`: ギミック・新しい技術を1つか2つ、深く
- `## 気になるところ`: 公式か出典で分かる弱み(電池・重さ・対応機種など)。無ければ省く
- 必要なら `## 発売と価格`
- 「日本で使える？」の欄・仕様表・買うボタン・代わり・出典は build.py が front matter から出すので、本文に書かない
