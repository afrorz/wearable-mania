# Wearable Mania の見た目の基準(DESIGN.md)

ページを足す・部品を作る・見た目を直すときに、毎回読む。
決まった見た目(ガラス・色・書体・トップの形)は `CLAUDE.md` の「見た目」の節が正で、ここには写さない。ここに書くのは「何を手本にしているか」「何をやらないか」「仕上がりをどう確かめるか」。
(2026-11-28 作成。きっかけはマネタイズノート #20「AIに『きれいにして』と言うな」)

## 1. 手本にしているもの(2026-11-28 に見た)

見た目を丸写しにはしない。まねるのは下の「特徴」までにする。

| 手本 | 何を取るか |
|---|---|
| Oura(ouraring.com) | **淡い暖色の地に、細い明朝寄りの大見出しと余白。** 製品の写真は指輪を大きく1〜2個だけ。体の場面は人の写真のカードで横に流す。色数が少なく、ボタンは黒に近い焦げ茶の丸い札だけ |
| WHOOP(whoop.com) | 黒い地に、水滴のついたバンドの寄りの写真。見出しは大きく細いサンセリフ。プランは3枚のカードで、それぞれ地の色を淡く変えて区別。**数字(14日・¥)で比べさせる** |
| XREAL(xreal.com) | 製品を斜めに大きく浮かせ、光の帯を1本だけ通す。黒〜オレンジの強い色は「セール」の時だけ。メガネの形が一目でわかる角度を選んでいる |
| Wareable(wareable.com) | 同じウェアラブル専門の媒体。白地に黒の帯、カードは写真が主役で題名は短い。**写真の地を暗くそろえている**ので一覧が締まって見える |

共通して効いていること:
- 主役は「身につけた形」が分かる写真。写真の角度と地の色をそろえると一覧がまとまる
- 大見出しは細い字か、細い字と太い字の混ぜ(Wearable Mania の Lexend 200/800 と同じ方向)
- 差し色は1つの場面に1色。強い色はセール・警告など「ここだけ」に使う

## 2. やらないこと(AIっぽく見える物)

- 光の玉・すりガラスを**ページの全部の箱**に使う(ガラスはヘッダー・カード・JAPAN CHECK の板まで。本文の段まで全部ガラスにしない)
- 紫〜ピンクのグラデーションの文字、光るボタン
- 数字カードを3〜4枚同じ大きさで並べるだけの段(JAPAN CHECK の6項目は色の札＋短い言葉で、ダッシュボード風の大きな数字にしない)
- 見出しの1語だけ斜体・色付き、絵文字の見出し
- 「未来の」「革新的な」のような中身の無い形容詞の見出し(製品の数字か、日本で使えるかを見出しに入れる)
- Inter 等の「とりあえずの英字書体」(英字は Lexend・JetBrains Mono だけ)
- 上の例に無くても、**ほかのAI製サイトと同じに見えたら作り直す**。このリストは流行で古くなるので、3の採点で見つけたら書き足す

## 3. 仕上がりの確かめ方

1. **新しいページの形・大きな部品は、違う手本に基づく3案を1枚のモックに並べて本人に選んでもらう。** 選ぶまで本番に入れない(`mock/` に置く。公開しない)
2. **辛口の採点を、作った会話とは別の目で行う**(新しい会話か、別のエージェント)。頼み方:
   > このサイトを初めて見る人として、ouraring.com・whoop.com・xreal.com と比べて10点満点で採点してください。AIが作ったように見える所を影響の大きい順に全部挙げ、容赦なく指摘してください。最後に9点にする改善案を3つ出してください。
   - 出た指摘は本人に見せてから直す(見た目の決定は本人)
3. **スマホ幅 375px** で、横はみ出し・余白・ボタンの押しやすさを見てから完了にする(CLAUDE.md の決まりと同じ)
